# 需求对应关系与交付边界

需求原文为同目录 `BUILD_SPEC.md`。软件从零建立独立模块，参考 `hiplace_impl` 的文件结构经验，没有直接复用其旧优化器和旧距离判断。需求中的示意接口由实际类型和 CLI 落实，下面列出对应关系及尚未完成的外部验收。

| 基准章节 | 实现 | 验证/边界 |
|---|---|---|
| §3 输入契约 | `io/epro2.py`、`io/cluster_csv.py`、`config.py` | 单日志格式、显式单位、完整 CSV，未知项拒绝；真实原生版本仍待验收 |

## 里程碑状态

M0～M6 的实现已通过随包合成夹具及回归测试。M7 的文件写回和内部读回通过，**立创 EDA 打开/另存验收仍为 PENDING**，因此 M7 不能宣称全部外部验收完成。M8 缺少用户真实板及规则输入，尚未开展真实板验证。

`sample_runs` 中记录的是实际运行输出。未加入虚构的真实板结果、线长改善比例、安规认证或性能上限结论。多种子实验脚本已提供，但此次仅对其 A+B 单种子模式做冒烟运行；不能把它当成完整统计实验。

## 有意采用的保守实现

- 文档第 7.6 节明确允许 NumPy 解析梯度，本版本只维护这一套内核；不提供名义上的 `torch_float64` 空后端。
- 板框首版为轴对齐矩形，域规划为横/纵简单两域分割。复杂拓扑可能有解而当前搜索找不到。
- 簇采用真实成员布局的外包矩形；圆形铜由外包 32 边形近似。方向改变后重算几何，不缩放实体。
- 投影图固定一个分离拓扑，在候选层更换拓扑。细粒度导体/非线性规则由独立检查器筛选，不把罚函数值当可行证明。
- 接口沿边位置在 P1 采样后冻结；C 不移动固定件、接口或桥接件。`edge_slide` 表示允许搜索的机械自由度，不表示 B/C 仍连续滑动。
- 硬簇区域的面积取完整宽×高。C 的信赖圆使用内接方盒，是较保守的可行子集。
- 固定板框优先电气意图、加权 HPWL、簇外包面积、扰动；估算默认意图、板面积、HPWL、扰动。配置允许显式线长优先。
- `PROVEN_INFEASIBLE` 保留状态定义，但当前搜索不会生成全问题不可行证明。一个 OSQP 子问题失败不会被提升为全局无解。
- 运行预算为合作式软截止，单次求解器调用或完整检查可以越过截止点少量时间。

## 仍需真实数据推动的工作

1. 选定立创 EDA 版本与真实工程，验证坐标/角度、原生记录语义及打开另存流程。遇到未支持的记录先补夹具和格式契约，再扩展适配器。
2. 在固定板、无板框板和人工密排板上运行至少 5 个固定种子，保留所有失败样本。
3. 实现并独立验证扁平梯度基线和关闭分级策略的消融；当前运行器不包含这两项。
4. 对 300 器件规模进行 profiling；当前完整校验仍含两两导体检查，未声称达到工业性能。
5. 在目标 Windows/Ubuntu、目标 Python 与依赖组合下运行测试，随后更新环境锁定记录。

这些是明确的验收/能力边界，不会通过降低硬约束或自动猜测规则补齐。

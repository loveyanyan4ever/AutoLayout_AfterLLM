# 0.2.0 修复说明

本版针对上一轮只读审查的 R01～R12，以及上传数字电源板在读取阶段触发的 `LOG_RECORD` 失败。保留原来的分簇、簇间优化、整体微调结构和梯度内核；没有通过删除器件、忽略约束或修改原始需求来得到输出。

具体测试数量、合成示例结果和真实板 HPWL/耗时见 [验证报告](TEST_REPORT.md)。本文件说明改动，不替代运行证据。

## 审查问题修复

| 编号 | 修改 | 验证要点 |
|---|---|---|
| R01 | 导电机械本体独立加入导体集合，即使该封装同时有 pad | 小 pad 不能掩盖金属本体距离不足；局部候选与最终检查一致 |
| R02 | 普通电气域器件的 pad 不得通过 `pad_domains` 越域绕过桥接模板 | 跨域必须声明完整 bridge 域与模板；仍检查桥接内部铜间距 |
| R03 | PAD_NET 按完整组件/焊盘编号/稳定图元 ID 验证 | 错误 ID、未知 ID 和身份冲突拒绝；同号物理 pad 不合并 |
| R04 | CSV 使用严格表头与逐行列数检查 | 重复表头、多余或缺失单元格报错，不再静默取值 |
| R05 | 拆簇前保留原簇名称并检测生成 ID 碰撞 | 自动拆簇不会与已有同名簇合并 |
| R06 | 簇内初始方向先满足允许角集合，局部候选检查覆盖方向 | 源角度不被允许时可以重新初始化；不同器件的方向要求不会被整簇旋转掩盖 |
| R07 | 硬引脚距离加入初始化与优化投影的可行化过程 | 可行的距离上限能被满足；不可行上限仍失败，不放宽规则 |
| R08 | 紧凑度只统计相关可动成员，排除固定障碍虚拟变量 | 同形状整体平移不改变紧凑度，远处障碍不产生无意吸引 |
| R09 | 多边形先检查有限坐标、退化和自交，再作凸性/包络处理 | 自交五角星等非法输入在几何计算前拒绝 |
| R10 | C 阶段独立验收核对参考板框、域/簇区域和已冻结机械姿态 | 有效形状的擅自扩板或区域变化也会被检出 |
| R11 | `evaluate` 对不合法结果返回非零退出码；配置/YAML 错误结构化返回 | 自动化不能仅因进程退出 0 而误判布局通过 |
| R12 | 导出同时保护目标 `.epro2` 与 `.export.json`，提交失败时回滚本次输出 | 原始工程、既有旁文件和非本次创建的文件不会被覆盖 |

补充了 Adam 接受/拒绝/再接受序列、硬距离交集投影、局部快速排除与完整检查一致性等测试。距离/顺序规则引用多个同号物理焊盘时明确拒绝歧义；保留这些物理焊盘的正常导入。有限差分仍用于验证目标导数，但测试也检查公式的平移不变性和规则含义。

## 原生 epro2 适配

原失败由对空负载执行 `json.loads('')` 引起。新版按原生日志语义处理空负载墓碑和版本优先级，保留历史原文；JSON 损坏、普通 null 或未知删除结构不会被一律吞成删除。相同 ticket 使用文档 client 规则，不能仅按行顺序覆盖。

新增 `easyeda_pro_v3` 适配标识并保留 `reference_v3` 参考输入兼容性。支持已验证的 Device→Footprint 间接引用、明确非几何元数据、原生 OUTLINE 层板框、封装内 VIA、同编号多物理 PAD，以及圆/椭圆/长圆、多边形外包与圆孔/槽孔。孔偏移单独作用于孔，不能平移铜盘。

真实板恢复全部 103 个器件、25 个封装和 269 个物理电气对象：265 个 PAD、4 个封装 VIA。四个 VIA 通过 PCB PAD_NET 映射到 GND，不能因为封装中的空网名而从网表漏掉。没有目标 POUR 的孤儿 POURED 派生记录保留原文、排除布局建模；活动覆铜或关联不明确时仍拒绝。

`geometry.source_body_policy: source_courtyard_or_assembly` 支持有明确来源的本体层保守包络。多边形焊盘的路径坐标解释需要 `polygon_path_frame`；真实案例使用 `conservative_union` 覆盖两种可能解释，报告中不冒充精确恢复。具体依据与限制见 [NATIVE_FORMAT_NOTES.md](NATIVE_FORMAT_NOTES.md)。

## 机械预布局、父功能组和写回

新增 `corner` 模板，按完整占位包络与板角内缩距离放置机械件；新增 `edge_band`，保持源方向，将接口完整占位放在指定板边内侧。它不自动推断外部插拔方向，已有明确插拔方向的规则继续使用 `edge_slide`/`edge_choice`。源锁定件仍受锁定约束。

功能簇 CSV 可增加 `parent_cluster_id`。L1 继续形成局部簇，L2 作为父功能组参与紧凑度目标和评估；L2 不被混用为电气隔离域，也没有额外承诺 L2 硬区域互斥。同一 L1 声明多个父组会拒绝。

原生 JSON 的 NaN、Infinity 及浮点溢出被结构化拒绝；坐标双别名须一致，导出同步更新所有现有别名，写出禁止非有限值。

导出向选中 PCB 追加 COMPONENT 位姿事件及需要的 ATTR 跟随事件，使位号/属性文字随器件平移旋转。估算板框写为原生 OUTLINE 层折线。原始日志、未选中板、共享封装、原理图、完整连接关系和其他 ZIP 成员保留，并进行写回核对。

## 真实案例的明确决策

用户允许重新预布局机械孔和接口，确认 L2 为共地系统上层功能组。真实配置因此使用 MAIN 与 MECH，保留原始 L1/L2 的全部标签和证据；没有凭空设置高低压隔离对。

机械间距 0.30 mm、异网铜间距 0.25 mm、M3 8×8 mm 装配包络和裸测试点 0.7×0.7 mm 接近包络都是明确可修改的研究默认，来源写入 `rules.basis`。本次真实板所有器件保持源 0°角度，仅优化位置；真实原生非零角度转换没有经过编辑器确认。

原生编辑器验收仍为 **PENDING**。程序读回、自动测试和独立数值检查不能代替立创 EDA 打开/另存、原生 DRC、布线和实际制造验收。未支持的几何或不可满足的约束仍应返回失败，不能宣称任意正常工程都必然成功。
